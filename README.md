# Енергооблік Полтави

Сайт для енергоменеджера громади. З оригінальних XLSX-звітів uMuni він формує паспорти будівель, рейтинг у межах категорії та зведення базового енергоспоживання за 2025 рік. У «Відкритих даних» вкладка «Річне споживання» показує всі рядки зі звітів за будівлями. Їх можна знайти за адресою, відібрати за роком і завантажити у CSV. Вкладка «Лічильники з імпорту» показує номер із реєстру, внутрішній ID uMuni, модель, послугу й відомі реквізити закладу. Для нового показання підставляється однозначний номер приладу. Якщо такого номера немає, використовується ID uMuni. Фактичні показання можна ввести у таблиці або додати журналом CSV у розділі «Імпорт». Вкладка «Результат CSV» показує таблицю перед вивантаженням накопичувального `resources.csv`.

## Локальний запуск

Відкрийте [dist/index.html](dist/index.html) у браузері або виконайте команду з кореня репозиторію:

```sh
python -m http.server 8000 --directory dist
```

Сайт буде доступний за адресою [localhost:8000](http://localhost:8000/). Збірка та встановлення пакетів не потрібні.

## Дані

Перший запуск відкриває порожній робочий простір. У розділі «Імпорт» наведено п’ять назв XLSX із папки треку. Для початку оберіть `Buildings_Info_Report (1).xlsx` і `Річне_використання_ресурсів (49).xlsx`. Щоб повторити перевірку з нуля, натисніть «Очистити дані сайту» на тому самому екрані. Імпортовані дані зберігаються у браузері.
