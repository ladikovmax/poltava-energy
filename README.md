# Енергооблік Полтави

Сайт для енергоменеджера громади. З оригінальних XLSX-звітів uMuni він формує паспорти будівель, рейтинг у межах категорії та зведення базового енергоспоживання за 2025 рік. Окремий розділ готує накопичувальний `resources.csv` з журналу показань після перевірки користувачем.

## Локальний запуск

Відкрийте [dist/index.html](dist/index.html) у браузері або виконайте команду з кореня репозиторію:

```sh
python -m http.server 8000 --directory dist
```

Сайт буде доступний за адресою [localhost:8000](http://localhost:8000/). Збірка та встановлення пакетів не потрібні.

## Дані

За замовчуванням сайт показує знеособлений приклад. Для роботи з власними будівлями оберіть реєстр і річні XLSX у розділі «Імпорт». Завантажені користувачем дані зберігаються в його браузері.
