# Енергооблік Полтави

Сайт для енергоменеджера громади. З оригінальних XLSX-звітів uMuni він формує паспорти будівель, рейтинг у межах категорії та зведення базового енергоспоживання. У «Відкритих даних» першою відкривається таблиця `resources.csv` у форматі опублікованого звіту Івано-Франківська. Тут можна додати попередній ресурс, перевірити показання та завантажити результат або порожній шаблон.

Кожний рядок містить одне показання. Таблиця й CSV мають однакові заголовки.

```csv
uid,date,organizationName,organizationId,providerName,providerId,meterNumber,type,quantity,unitName
```

Дати мають формат `РРРР-ММ-ДД`, десяткові значення записуються через крапку. Ознайомитися з річним споживанням і знайти лічильник можна в сусідніх вкладках. Нове показання можна ввести з реєстру приладів або додати журналом CSV.

## Локальний запуск

Відкрийте [dist/index.html](dist/index.html) у браузері або виконайте команду з кореня репозиторію:

```sh
python -m http.server 8000 --directory dist
```

Сайт буде доступний за адресою [localhost:8000](http://localhost:8000/). Збірка та встановлення пакетів не потрібні.

## Дані

Перший запуск відкриває порожній робочий простір. У розділі «Імпорт» наведено п’ять назв XLSX із папки треку. Для початку оберіть `Buildings_Info_Report (1).xlsx` і `Річне_використання_ресурсів (49).xlsx`. Щоб повторити перевірку з нуля, натисніть «Очистити дані сайту» на тому самому екрані. Імпортовані дані зберігаються у браузері.

## Файли проєкту

| Папка | Вміст |
| --- | --- |
| `dist/` | Головна сторінка сайту для GitHub Pages |
| `dist/js/` | Імпорт, розрахунки, локальне збереження та формування звіту |
| `dist/css/` | Стилі сторінок і таблиць |
| `dist/assets/` | Піктограма сайту |
| `dist/vendor/sheetjs/` | Бібліотека читання XLSX та [її ліцензія](dist/vendor/sheetjs/SHEETJS-LICENSE.txt) |
| `tests/` | Перевірка формату CSV командою `node --test tests/resources-csv.test.cjs` |
| `.github/workflows/` | Публікація на GitHub Pages |
